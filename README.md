# 中医望诊自查 · 手诊 + 目诊

一个仓库收纳两套纯本地、单文件、拍照不上传的中医望诊自查工具，统一由 `index.html` 首页入口分发。

| 模块 | 文件 | 体系 / 说明 |
|---|---|---|
| 首页入口 | `index.html` | 手诊、目诊两个模块的导航页 |
| 观手知健康（手诊） | `hand-diagnosis.html` | 蔡洪光《观手去百病》+ 田鹏霞《观手知健康》双体系：拍照自动分区取色分析、体质辨识 + 五脏状态评分；并按体质推荐外治法（按摩/拔罐/艾灸/线灸/刮痧）与中成药参考；报告后附 AI 解读助手（支持上传手部照片对话） |
| 望目智诊（目诊） | `eye-diagnosis.html` | 拍眼分析，自动量化虹膜盘面、白睛血丝形态、色泽纹理，叠加分区标注生成报告 |

## 使用方法

整个项目只有三个 HTML 文件，**双击 `index.html` 即可在浏览器打开**首页入口，再进入对应模块；无需安装依赖、无需联网、不上传任何数据。

# 望目智诊 · 拍眼分析网页

基于中医「望目」与现代虹膜反射区思路的拍眼自查工具，单文件 HTML、纯本地运行、不上传任何数据。

- 文件：`eye-diagnosis.html`
- 功能：拍照/选图上传眼睛照片，Canvas 自动量化虹膜盘面、白睛血丝形态、色泽与纹理，并叠加十二时区/分区标注，生成望目分析报告
- **AI 解读助手**：报告下方内置对话面板，基于当前报告用大白话解读、给日常防护建议，并强调「非医疗诊断」。在面板设置中填入您自己的 OpenAI 兼容接口（API Key 仅存本机），即可自由追问
- 用法：本地双击打开，或在部署的 WorkBuddy 应用页直接使用

# 观手知健康 · 手诊自查网页

基于 **蔡洪光《观手知健康——经络全息手诊》** 与 **田鹏霞《观手知健康》** 两套体系整理的单文件手诊自查工具。

## 使用方法

整个项目只有一个文件 `index.html`，**双击即可在浏览器打开**，无需安装任何依赖、无需联网、不上传任何数据。

## 功能流程

| 步骤 | 功能 |
|---|---|
| STEP 1 拍照 · 自动分析 | 调用摄像头/相册拍手掌与指甲照片，Canvas **分区取色**：把手掌自动切成大鱼际/小鱼际/掌心/掌根/四指根/指尖 9 个部位，逐区与手部平均肤色对比，标出偏红/白/黄/青/暗与青筋明显处（即"分析手各部分的颜色"）；指甲走整图色调分析 |
| STEP 2 报告自动生成 | 拍照完成即自动生成，**无需任何勾选**：体质辨识（平和/气虚/血瘀/湿热/痰湿/气郁/阳虚/阴虚内热）+ 综合评分（0–100）+ 五脏状态分析评分卡（心/肺/肝/脾/肾）+ 详细诊断报告（体质特征/五脏分析/季节养生）+ 重点调理建议（穴位+饮食+起居）+ 就医提醒 |

## 五脏评分是怎么算出来的

- **拍照（STEP 1）**：系统把每张手掌照片切成 9 个部位、各自取色，与您手部平均肤色对比算出部位颜色异常（偏红/白/黄/青/暗）与青筋密度，再按"手指根全息"把每个部位映射到对应脏腑系统 → 这才是真正"分析手各部分的颜色"。
- 各脏腑的分区颜色信号合并为权重后换算成 0–100 分：分数越高状态越好，≥80「状态良好」、60–79「需要注意」、<60「建议调理」。
- 体质辨识取手部信号最突出的体质倾向；分数仅反映手部观察信号，**不是患病概率，更不是严重程度**。

## 特点

- **纯本地运行**：照片与分析全部在本机内存处理，刷新即消失，不上传任何服务器
- **全自动、零勾选**：只需拍照，报告自动生成；没有任何需要打勾的步骤
- **大白话解读**：所有结论按书中体系解释，但用口语化文字呈现
- **报告自动生成**：拍照后自动刷新，无需点按钮

## 说明

- 手诊属传统经验总结，本工具**仅供养生文化学习与自我观察参考，不构成医疗诊断**；如遇"建议就医"标记项，请及时咨询执业医师。
- 自动图像分析基于照片色彩与纹理的客观量化，受光线、白平衡、拍摄角度影响；建议在自然光、纯色背景下拍摄。
- 本地双击打开时，拍照走系统相机/文件选择器；如需实时取景预览，可在本目录运行 `python3 -m http.server 8000` 后用 `http://localhost:8000` 访问。
